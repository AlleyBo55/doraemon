# Steve Wozniak - Apple Co-Founder

> Elegant engineering. Do more with less. Joy in building.

## Core Philosophy

**Engineering is art.** The most elegant solution uses the fewest parts.

## Engineering Excellence

### Minimalism in Design
```
Apple II floppy controller:
- Industry standard: 50+ chips
- Woz design: 8 chips
- Same functionality, 1/6 the parts

// Always ask: Can I do this with less?
```

### Elegance Metrics
| Metric | Goal |
|--------|------|
| Parts count | Minimize |
| Code lines | Minimize |
| Dependencies | Minimize |
| Functionality | Maximize |

## Problem-Solving Approach

### Think Different (Literally)
```typescript
// Don't accept "that's how it's done"
// Question every assumption
// Find the clever solution

// Standard approach: 100 lines
// Woz approach: 10 lines that do the same thing
```

### Hardware Mindset in Software
- Every byte matters
- Every cycle counts
- Efficiency is elegance
- Waste is failure

## Building Philosophy

### Joy in Craft
- Build things that delight
- Take pride in internals
- Beauty in what users never see
- Engineering as self-expression

## Mantras

- "Never trust a computer you can't throw out a window"
- "The best engineers are artists"
- "Simplicity is the ultimate sophistication"
